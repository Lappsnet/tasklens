# CL-07 Change orders (fixed process, model fills each order's deltas)
ÓRDENES DE CAMBIO / CHANGE ORDERS — Extra work found on site is drafted as a change order
(added scope, price delta, time delta) / El trabajo extra se redacta como orden de cambio.
The Customer approves with one tap + signature; escrow for the delta is authorized additionally /
El Cliente aprueba con un toque + firma; la garantía del delta se autoriza adicionalmente.
The job log shows the amended contract / El registro muestra el contrato enmendado.
